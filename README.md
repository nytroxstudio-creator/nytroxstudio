# ✦ Nytrox Studio — Official Website

> **Bold branding, VTuber characters, logo design, banners, and digital experiences crafted for creators who refuse to blend in.**

![Nytrox Studio](public/nytrox-logo-exact.png)

---

## ⚡ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/) with custom dark luxury theme & animations
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: Custom 60fps HTML5 Canvas localized starfield & cursor parallax, canvas-confetti

---

## 🚀 Key Features

1. **Authentic Brand Identity**:
   - Exact vector logo typography with custom wave `N` and signature 4-point sparkle star cluster (`✦`).
   - Refined, concentrated ambient glow with smooth 500ms hover transition.
2. **Animated Starfield with Localized Cursor Physics**:
   - 320+ stars across depth layers with smooth proximity reaction around the cursor (no whole-screen jitter).
   - Subtle 5% soft depth blur filter.
3. **Direct Project Consultation Form**:
   - Inquiries sent directly to `nytroxstudio@gmail.com` capturing full brief details (service, budget, timeline, contact handle).
   - Celebratory confetti and structured submission receipt.
4. **Interactive Capabilities & Filterable Portfolio**:
   - 8 bespoke studio services with deliverable breakdowns.
   - High-res portfolio gallery with fullscreen interactive lightbox viewer.
5. **Creator Testimonials**:
   - Verified review wall with interactive review submission.
6. **Social Connectivity**:
   - Direct links to **Instagram** (`@nytroxstudio`), **X / Twitter** (`@nytroxstudio1`), and **LinkedIn Profile**.

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## ☁️ Deploy to Vercel (1-Click Ready)

This repository is pre-configured with `vercel.json` for instant deployment on [Vercel](https://vercel.com/):

1. Import this repository in your Vercel Dashboard: `https://github.com/nytroxstudio-creator/nytroxstudio`
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy** 🚀
